<header class="page-heading">
  <p class="eyebrow">Get Viamiora</p>
  <h1>Distribution is being qualified.</h1>
  <p>Viamiora currently supports macOS 14.4 and later. The first public build will be Developer ID signed, notarized and tested as an installed application before it is offered here.</p>
</header>

<section class="install-step">
  <h2>Homebrew</h2>
  <p>The Viamiora cask will be published after the first signed GitHub release. The command is intentionally not shown before the cask exists.</p>
</section>

<section class="install-step">
  <h2>Direct download</h2>
  <p>A universal macOS archive will be available from the <a href="https://github.com/YunaBraska/Viamiora/releases">Viamiora releases</a> after notarization and installed-app checks pass.</p>
</section>

<section class="install-step">
  <h2>Updates</h2>
  <p>Automatic direct-download updates will be added only with a signed update feed and verified upgrade and rollback behavior. Until then, releases remain explicit downloads.</p>
</section>
